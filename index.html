Kelana: Aplikasi Server Pembelajaran Digital Berbasis Python Terintegrasi Papan Interaktif Digital

Belajar optimal walau internet terkendala

KELANA adalah aplikasi server pembelajaran digital luring–daring untuk sekolah: guru berbagi berkas dan materi, murid mengerjakan kuis, dan hasilnya terekam otomatis — dengan atau tanpa internet.

Coba Demo Pesan KELANA

Dashboard

KELANA dikembangkan oleh Wartam, S.Pd., guru Matematika SMP Negeri 4 Majenang, Kabupaten Cilacap. Aplikasi ini lahir dari kebutuhan nyata di kelas: sekolah belum memiliki internet kabel dan Papan Interaktif Digital belum termanfaatkan optimal, sementara hampir seluruh murid memiliki HP. KELANA dirancang dua opsi — KELANA Daring bagi murid yang memiliki kuota, dan KELANA Luring melalui wifi/LAN sekolah bagi yang tidak — sehingga tidak ada murid yang tertinggal.

Satu perangkat per username murid

Setiap murid masuk dengan username sendiri. Masuk dari perangkat baru akan mengakhiri sesi lama, jadi satu username hanya aktif di satu perangkat.

Berbagi berkas luring–daring

Guru membagikan materi dan berkas lewat server sekolah maupun daring, dan murid mengunduhnya dari HP atau laptop masing-masing.

Kuis dengan koreksi otomatis

Kuis interaktif terintegrasi dengan koreksi otomatis, sehingga guru langsung melihat hasil tanpa memeriksa satu per satu.

Rekap hasil unduh CSV

Seluruh hasil kiriman murid terekam otomatis dan dapat diunduh sebagai CSV untuk diolah lebih lanjut.

Admin bertingkat

Admin utama dan admin biasa dengan hak akses berbeda; guru/admin mengatur username dan materi per murid.

Terintegrasi Papan Interaktif Digital

Papan Interaktif Digital menjadi pusat kendali: guru mengelola username, materi, dan hasil murid langsung dari layar kelas.

Jalan dengan atau tanpa internet

KELANA tetap berjalan di jaringan lokal sekolah ketika internet berkendala, dan tetap dapat diakses daring ketika internet tersedia.

Cara Mendapatkan KELANA

Empat langkah mudah untuk menghadirkan KELANA di sekolah Anda.

  1. Isi formulir pemesanan

    Isi Formulir Pemesanan Aplikasi Kelana dengan data sekolah Anda.

  2. Donasi seikhlasnya

    Donasi seikhlasnya via Bank BRI atas nama Wartam sebagai dukungan pengembangan KELANA.

  3. Verifikasi Admin

    Pesanan diverifikasi, lalu disetujui. Setiap sekolah menerima satu nomor seri.

  4. Terima nomor seri + paket

    Setelah disetujui, sekolah menerima nomor seri dan paket KELANA siap dipasang di komputer sekolah.

Lisensi: satu nomor seri per sekolah. Identitas lisensi disimpan di berkas lisensi.txt di samping aplikasi KELANA.

Tata Cara Mengunduh Paket KELANA

Lima langkah untuk mengunduh paket KELANA sekolah Anda setelah pesanan disetujui.

  1. Pesan KELANA

    Isi Form Pemesanan Aplikasi Kelana (jika belum mengisi) dengan data sekolah dan bukti transfer.

    Buka Form Pemesanan →

  2. Tunggu persetujuan

    Admin memeriksa pesanan Anda dan menyetujuinya. Nomor seri Anda adalah KELANA-NPSN (NPSN sekolah Anda).

  3. Cek status

    Buka halaman Cek Status & Unduhan, masukkan NPSN sekolah Anda, lalu klik “Cek”.

    Cek Status & Unduh →

  4. Unduh paket

    Bila sudah disetujui, muncul nomor seri dan tombol “Unduh Paket KELANA”. Klik tombol itu; folder Drive sekolah Anda terbuka. Unduh isinya: lisensi.txt, kelana.exe, dan PANDUAN-EXE.txt.

  5. Jalankan

    Ikuti PANDUAN-EXE.txt untuk menjalankan KELANA di komputer Windows sekolah Anda. Letakkan lisensi.txt di samping kelana.exe.

Bila status masih “Menunggu”, pesanan Anda belum disetujui — silakan cek berkala. Bila ada kendala, hubungi Wartam melalui WhatsApp.

Panduan Mengonlinekan KELANA

KELANA bisa diakses lewat internet (daring) bila dijalankan di sebuah VPS. Berkas kelana.py yang sama dipakai luring maupun daring; yang berbeda hanya tempat menjalankannya.

Persyaratan

Sebelum memulai, siapkan hal-hal berikut:

  • Server (VPS): VPS dengan Ubuntu 24.04, minimal 1 vCPU / 1 GB RAM / 10 GB disk (disarankan 2 vCPU / 2 GB RAM / 40 GB). Server harus punya alamat IP publik, akses SSH, dan hak sudo/root. Port 80 (HTTP) dan 443 (HTTPS) harus terbuka di firewall/security group VPS. (Bila memakai VPS Windows, lihat bagian “Bila memakai VPS Windows” di bawah.)
  • Domain: sebuah domain atau subdomain (contoh: kelas.sekolah.sch.id), beserta akses ke pengaturan DNS untuk menambah record A yang mengarah ke IP VPS.
  • Perangkat lunak: Python 3, Caddy (reverse proxy + HTTPS otomatis), git, dan systemd — semuanya tersedia di Ubuntu.
  • Berkas KELANA: kelana.py, lisensi.txt (dari paket unduhan sekolah), kode.txt (username murid), kode-admin.txt (username admin), dan folder publik/ berisi materi.
  • Kemampuan dasar: menjalankan perintah di terminal dan memakai SSH.

Langkah 1 — Siapkan VPS

Buat VPS Ubuntu 24.04 di penyedia layanan pilihan Anda, catat alamat IP publiknya, dan pastikan port 80 dan 443 terbuka. Masuk ke VPS lewat SSH (ganti ALAMAT-IP-VPS dengan IP VPS Anda, dan ubuntu dengan username VPS Anda bila berbeda):

ssh ubuntu@ALAMAT-IP-VPS

Langkah 2 — Pasang Python, git, dan Caddy

Di dalam VPS, jalankan perintah berikut:

sudo apt update
sudo apt install -y python3 git
sudo apt install -y debian-keyring debian-archive-keyring apt-transport-https curl
curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/gpg.key' | sudo gpg --dearmor -o /usr/share/keyrings/caddy-stable-archive-keyring.gpg
curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/debian.deb.txt' | sudo tee /etc/apt/sources.list.d/caddy-stable.list
sudo apt update
sudo apt install -y caddy

Langkah 3 — Salin berkas KELANA ke VPS

Dari laptop, salin folder jalan KELANA ke VPS (sekali saja):

scp -r kelana ubuntu@ALAMAT-IP-VPS:/home/ubuntu/kelana

Isi folder kelana: kelana.py + kode.txt + kode-admin.txt + publik/ + lisensi.txt (folder hasil/ boleh kosong). Untuk pembaruan berikutnya, cukup ganti kelana.py saja — jangan timpa publik/, kode.txt, kode-admin.txt, atau hasil/.

Langkah 4 — Pasang service systemd (jalan otomatis)

Service membuat KELANA berjalan terus di latar belakang dan hidup lagi sendiri bila server di-restart. Berkas kelana.service tersedia di folder deploy-vps/ pada repo KELANA. Di VPS, jalankan satu per satu:

sudo cp /home/ubuntu/kelana/kelana.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now kelana
systemctl status kelana --no-pager | head -5

Baris terakhir harus menunjukkan active (running).

Langkah 5 — Arahkan subdomain lewat Caddy (HTTPS otomatis)

Buka file Caddy, lalu tambahkan blok berikut di bagian paling bawah (ganti dengan subdomain Anda):

sudo nano /etc/caddy/Caddyfile
kelas.sekolah.sch.id {
        reverse_proxy 127.0.0.1:8000
}

Simpan (Ctrl+O, Enter, Ctrl+X), lalu muat ulang Caddy:

sudo systemctl reload caddy

Caddy otomatis mengurus sertifikat HTTPS (Let’s Encrypt).

Langkah 6 — Atur DNS

Di tempat Anda mengelola DNS domain, tambah record:

Type : A
Name : kelas
Value: ALAMAT-IP-VPS

Tunggu 5–15 menit agar DNS menyebar, lalu buka https://kelas.sekolah.sch.id.

Langkah 7 — Isi username dan lisensi

Edit dua berkas ini di VPS (satu username per baris):

/home/ubuntu/kelana/kode.txt       → username murid
/home/ubuntu/kelana/kode-admin.txt → username admin/guru

Letakkan lisensi.txt sekolah Anda di samping kelana.py. Segera ganti username admin bawaan admin: sesudah masuk, buat username admin sendiri di /admin, lalu hapus admin, karena admin mudah ditebak siapa pun. Perubahan username berlaku langsung tanpa restart.

Memperbarui KELANA

Bila ada versi baru, cukup ganti kelana.py lalu restart service (data tidak disentuh):

scp kelana.py ubuntu@ALAMAT-IP-VPS:/home/ubuntu/kelana/kelana.py
ssh ubuntu@ALAMAT-IP-VPS
sudo systemctl restart kelana

Atau pakai skrip update-vps.sh dari repo (git pull, salin kelana.py, restart service).

Keamanan

  • KELANA hanya mendengar di 127.0.0.1 — yang menghadap internet adalah Caddy dengan HTTPS. Port 8000 tidak perlu dibuka di firewall.
  • Ganti username admin bawaan admin segera setelah pemasangan pertama.
  • Berkas kode.txt, kode-admin.txt, dan isi hasil/ adalah data sekolah — jangan masukkan ke repo publik dan jangan dibagikan.
  • Perbarui server secara berkala (sudo apt update && sudo apt upgrade).

Bila ada masalah

  • Halaman tidak terbuka: periksa service (systemctl status kelana) dan Caddy (systemctl status caddy), pastikan DNS sudah mengarah ke IP VPS, dan pastikan port 80/443 terbuka.
  • Service tidak berjalan: lihat pesannya dengan journalctl -u kelana --no-pager | tail -20.
  • HTTPS belum aktif: Caddy baru bisa menerbitkan sertifikat setelah domain benar-benar mengarah ke IP VPS — tunggu penyebaran DNS, lalu sudo systemctl reload caddy.

Bila memakai VPS Windows

KELANA juga bisa di-online-kan di VPS Windows, hanya saja langkahnya memakai perkakas Windows. Linux tetap lebih sederhana dan disarankan bila Anda bebas memilih.

  • VPS Windows: VPS dengan Windows Server, akses Remote Desktop (RDP), dan hak administrator. Port 80 dan 443 harus terbuka di Windows Firewall dan di security group VPS.
  • Berkas KELANA: gunakan kelana.exe dari paket unduhan (tidak perlu memasang Python). Letakkan kelana.exe, lisensi.txt, kode.txt, kode-admin.txt, dan folder publik/ dalam satu folder, misalnya C:\kelana\.
  • Jalankan KELANA: buat berkas start-kelana.bat di folder tersebut dengan isi berikut, lalu jalankan sekali untuk mencoba:
set HOST=127.0.0.1
set PORT=8000
kelana.exe

Bila sudah jalan, buka http://127.0.0.1:8000 di peramban VPS untuk memastikan.

  • Caddy untuk Windows: unduh caddy.exe dari situs resmi Caddy, letakkan di folder yang sama, lalu buat berkas Caddyfile berisi (ganti dengan subdomain Anda):
kelas.sekolah.sch.id {
        reverse_proxy 127.0.0.1:8000
}

Jalankan dengan caddy run dari folder itu. Caddy otomatis mengurus sertifikat HTTPS.

  • Jalan otomatis saat server hidup: gunakan Task Scheduler (Penjadwal Tugas) — buat tugas yang menjalankan start-kelana.bat dan caddy run saat startup (pemicu “At startup”, dengan hak administrator).
  • Firewall: izinkan port 80 dan 443 di Windows Defender Firewall.
  • DNS: sama seperti Linux — record A subdomain ke IP VPS, lalu buka https://kelas.sekolah.sch.id.

Catatan: panduan Windows ini belum diuji ujung-ke-ujung di VPS Windows sungguhan. Bila Anda menemukan kendala, kabari pengembang KELANA lewat halaman Kontak.

Tanya Jawab

Apa itu KELANA?

KELANA adalah aplikasi server pembelajaran digital luring–daring berbasis Python. Guru berbagi berkas dan materi, murid mengerjakan kuis dengan koreksi otomatis, dan hasil kiriman terekam serta dapat diunduh sebagai CSV. KELANA terintegrasi dengan Papan Interaktif Digital sebagai pusat kendali di kelas.

Apakah KELANA butuh internet?

Tidak selalu. KELANA dirancang dua opsi: KELANA Daring bagi murid yang memiliki kuota, dan KELANA Luring melalui wifi/LAN sekolah bagi yang tidak. Ketika internet berkendala, pembelajaran tetap berjalan di jaringan lokal sekolah.

Bagaimana lisensi KELANA?

Lisensi KELANA bersifat lunak: setiap sekolah menerima satu nomor seri. Identitas lisensi disimpan di berkas lisensi.txt di samping aplikasi, dan ditampilkan di kaki halaman serta di halaman admin.

Perangkat apa yang dibutuhkan?

Untuk server: satu komputer sekolah (Windows atau mesin virtual Linux) yang terhubung ke jaringan sekolah. Untuk murid: HP atau laptop dengan peramban, terhubung ke wifi/LAN sekolah atau internet.

Berapa biayanya?

KELANA diperoleh dengan donasi seikhlasnya via Bank BRI atas nama admin untuk pengembangan. Isi formulir pemesanan, lalu pesanan diverifikasi sebelum nomor seri dan paket dikirim.
